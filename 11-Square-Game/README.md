# Square Game

## Overview
Square Game is a browser-based interactive game project. It demonstrates the implementation of game elements, user interactions, and basic game logic using frontend technologies.

## Live Demo
Not currently published.

## Source Code

## Features
- Interactive game interface.
- Square-based visual elements.
- User interaction.
- Dynamic game behaviour.
- JavaScript-based functionality.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- HTML file – Game structure.
- CSS file – Game board styling.
- JavaScript file – Game logic and interactions.

## How to Run
1. Clone the repository.
2. Open the `11-Square-Game` folder.
3. Locate `index.html`.
4. Open it in a browser.
5. Start playing.
