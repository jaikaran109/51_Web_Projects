# Shapes Game

A small shape-matching game built with HTML, CSS, and vanilla JavaScript.

## How to play

1. Select **Start game** to begin a 30-second round.
2. Read the target shape displayed above the choices.
3. Click the matching square, diamond, or circle to earn a point.
4. Keep matching shapes until the timer reaches zero.
5. Select **Play again** to start another round.

Your best score is saved in your browser with local storage.

## Run locally

Open `index.html` in any modern browser. No installation or build step is required.
