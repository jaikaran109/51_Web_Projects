# Gallery Project

## Overview
Gallery Project is a frontend application designed to present images or visual content in an organized gallery interface. It demonstrates how React components can be used to structure reusable UI elements.

## How to Run

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository.
2. Open the project directory.

   `cd 51_Web_Projects/19-Gallery-Project`

3. Install dependencies.

   `npm install`

4. Start the application.

   `npm run dev`

5. Open the localhost URL displayed in the terminal.
