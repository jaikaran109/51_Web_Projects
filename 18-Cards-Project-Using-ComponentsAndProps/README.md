# Cards Project Using React Components and Props

## Overview
Cards Project demonstrates the use of React components and props to build reusable card-based user interface elements.

The project introduces component-based frontend development and demonstrates how data can be passed between React components.

## How to Run

### Prerequisites
- Node.js
- npm
- Visual Studio Code

### Installation

1. Clone the repository.

   `git clone https://github.com/jaikaran109/51_Web_Projects.git`

2. Navigate to the project directory.

   `cd 51_Web_Projects/18-Cards-Project-Using-ComponentsAndProps`

3. Install dependencies.

   `npm install`

4. Start the development server.

   `npm run dev`

5. Open the localhost URL displayed in the terminal.
