## How to Run

### Prerequisites
- Node.js
- npm
- Visual Studio Code

### Installation

1. Clone the repository.

   `git clone https://github.com/jaikaran109/51_Web_Projects.git`

2. Navigate to the project directory.

   `cd 51_Web_Projects/25-UI-Project-Using-Tailwind`

3. Install dependencies.

   `npm install`

4. Start the development server using the configured command.

   `npm run dev`

5. Open the localhost URL displayed in the terminal.
