
# Amazon Clone

## Overview
Amazon Clone is a frontend web development project inspired by the design and layout of the Amazon e-commerce platform. It demonstrates how HTML and CSS can be used to create an online shopping interface.

This is an educational project and is not affiliated with Amazon.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/08-Amazon-Clone

## Features
- E-commerce-inspired homepage.
- Navigation bar.
- Product-oriented layout.
- Shopping website interface.
- CSS-based page styling.
- 📱 **Responsive Design** — adapts to desktop, tablet, and mobile screen sizes.

## Technologies Used
- HTML5
- CSS3

## Project Structure
- HTML file – Main webpage structure.
- CSS file – Styling and layout.
- Images – Website visual assets.

## How to Run
1. Clone the repository.
2. Open the `08-Amazon-Clone` folder.
3. Locate `index.html`.
4. Open the file in your browser.

## New Feature: Wishlist

This project now includes a category wishlist feature.

### Features
- Add categories to your wishlist.
- Remove categories from your wishlist.
- View all saved categories in a separate wishlist section.
- Dynamic wishlist count in the navigation bar.
- Wishlist data persists after refreshing the browser using localStorage.
- Responsive wishlist layout.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

### How to Run
1. Clone the repository.
2. Open the `08-Amazon-Clone` folder.
3. Start a local server:

   `py -m http.server 5500`

4. Open `http://localhost:5500` in your browser.
