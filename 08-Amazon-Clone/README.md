
# Amazon Clone

## Overview
Amazon Clone is a frontend web development project inspired by the design and layout of the Amazon e-commerce platform. It demonstrates how HTML and CSS can be used to create an online shopping interface.

This is an educational project and is not affiliated with Amazon.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/08-Amazon-Clone

## Features
- E-commerce-inspired homepage.
- Navigation bar.
- Product-oriented layout.
- Shopping website interface.
- CSS-based page styling.

## Technologies Used
- HTML5
- CSS3

## Project Structure
- HTML file – Main webpage structure.
- CSS file – Styling and layout.
- Images – Website visual assets.

## How to Run
1. Clone the repository.
2. Open the `08-Amazon-Clone` folder.
3. Locate `index.html`.
4. Open the file in your browser.

## Learning Outcomes
- Building website layouts.
- CSS Flexbox and Grid, where used.
- Navigation design.
- Frontend development fundamentals.
