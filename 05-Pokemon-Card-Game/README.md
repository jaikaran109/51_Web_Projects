
# Pokémon Card Game

## Overview
Pokémon Card Game is an interactive web project inspired by Pokémon cards. It demonstrates frontend development concepts through a card-based interface and game-related interactions.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/05-Pokemon-Card-Game

## Features
- Added a Pokémon-themed card interface featuring Pikachu, Charmander, Bulbasaur, and Squirtle.
- Implemented an interactive card-flipping memory matching mechanic.
- Added card matching logic with visual feedback for matched and unmatched pairs.
- Displayed Pokémon artwork, names, and types on the cards.
- Added dynamic game updates using JavaScript.
- Implemented move counting and an elapsed-time timer.
- Added a win message and Play Again functionality.
- Created a Personal Records section to track best moves, best time, and best score.
- Implemented a scoring system based on moves and completion time.
- Used localStorage to persist personal records across game sessions.
- Added accessible card labels and keyboard interaction support.
- Designed a responsive and engaging Pokémon-themed interface.

## How to Run
1. Clone the repository.
2. Open the `05-Pokemon-Card-Game` folder.
3. Locate `index.html`.
4. Open it in a modern browser.
