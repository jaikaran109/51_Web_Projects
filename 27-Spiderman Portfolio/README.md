## ✨ Overview

A modern, responsive portfolio designed with a sleek **red-and-black aesthetic**, smooth navigation, interactive components, and a structured layout.

The portfolio highlights my work in web development, problem-solving, and machine learning while providing an easy way to explore my projects and connect with me.

## 🚀 Key Features

| Feature               | Description                                   |
| --------------------- | --------------------------------------------- |
| 🎨 Modern UI          | Sleek red-and-black visual design             |
| 📱 Responsive Layout  | Optimized for different screen sizes          |
| 🧭 Smart Navigation   | Mobile menu with toggle functionality         |
| 📍 Active Navigation  | Highlights the section currently in view      |
| 📊 Dynamic Skill Bars | Skill indicators powered by `data-level`      |
| ⚡ MutationObserver    | Automatically synchronizes skill bar updates  |
| 💻 Terminal UI        | Developer-inspired interactive profile card   |
| 📂 Project Showcase   | Dedicated project and repository section      |
| 🏆 Coding Records     | Displays programming milestones               |
| 📬 Contact Section    | Quick access to social and professional links |

## ⚙️ Run Locally

Want to explore the project on your machine?

**1. Clone the repository**

```bash
git clone https://github.com/jaikaran109/jaikaran-portfolio.git
```

**2. Navigate to the project folder**

```bash
cd jaikaran-portfolio
```

**3. Launch the project**

Open `index.html` using VS Code Live Server or your preferred browser.
