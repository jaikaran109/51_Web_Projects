# Tribute Website

## About
A tribute website created to showcase information about an inspiring personality. It presents content in a structured and visually appealing format.

## Features
- Biography and introduction section.
- Organized content layout.
- Attractive webpage design.
- Image and text presentation.
- Responsive styling.

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Open the project folder.
2. Locate index.html.
3. Double-click the file to open it in your browser.
4. Explore the tribute webpage.

## Project Structure
- index.html - Main webpage.
- CSS files - Page styling.
- Images - Visual assets used in the website.
