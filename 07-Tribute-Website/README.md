
# Tribute Website

## Overview
Tribute Website is a frontend project created to present information about an inspiring personality. It uses a structured webpage layout to organize text, images, and other informational content.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/07-Tribute-Website

## Features
- Tribute introduction section.
- Informational content presentation.
- Image and text layout.
- Organized webpage sections.
- Simple and readable design.

## Technologies Used
- HTML5
- CSS3

## Project Structure
- HTML file – Contains the tribute content.
- CSS file – Handles page styling.
- Images – Stores visual assets.

## How to Run
1. Clone the repository.
2. Open the `07-Tribute-Website` folder.
3. Locate the main HTML file.
4. Open it in your browser.
