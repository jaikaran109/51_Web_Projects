# Insta App

## How to Run

### Prerequisites
- Node.js
- npm
- Visual Studio Code

### Installation

1. Clone the repository.

   `git clone https://github.com/jaikaran109/51_Web_Projects.git`

2. Navigate to the project directory.

   `cd 51_Web_Projects/20-Insta-App`

3. Install dependencies in the relevant application directory.

   `npm install`

4. Check `package.json` for the available start command.

5. Configure any required environment variables.

6. Start the backend and frontend using their configured commands.
