# Student Management System

## Overview
Student Management System is a web application designed to manage student-related information. It demonstrates the integration of frontend technologies, Node.js, and MongoDB for developing a database-backed application.

## How to Run

### Prerequisites
- Node.js
- npm
- MongoDB
- Visual Studio Code

### Installation

1. Clone the repository.

   `git clone https://github.com/jaikaran109/51_Web_Projects.git`

2. Navigate to the project directory.

   `cd 51_Web_Projects/24-Student-Management-System`

3. Install dependencies in the relevant application directories.

   `npm install`

4. Configure the MongoDB connection.

5. Set the required environment variables.

6. Run the backend using the command defined in `package.json`.

7. Start the frontend using its configured command.

8. Open the application in your browser.
