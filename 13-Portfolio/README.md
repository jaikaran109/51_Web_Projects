# Personal Portfolio Website

## Overview
Personal Portfolio Website is a frontend project designed to showcase an individual's profile, skills, projects, and professional information through a personal website.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/13-Portfolio

## Features
- Personal introduction section.
- Profile information.
- Skills presentation.
- Project showcase, where included.
- Contact information section.
- Personalized webpage design.

## Technologies Used
- HTML5
- CSS3

## Project Structure
- HTML file – Main portfolio structure.
- CSS file – Styling and layout.
- Images – Profile and project assets.

## How to Run
1. Clone the repository.
2. Open the `13-Portfolio` folder.
3. Locate the main HTML file.
4. Open it in a browser.
