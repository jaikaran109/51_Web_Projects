
# Job Application Form

## Overview
Job Application Form is a web-based project designed to provide an organized interface for collecting job applicant information. It demonstrates how HTML forms and CSS can be used to create a structured application page.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/04-Job-Application

## Features
- Structured job application form.
- Applicant information input fields.
- Organized form sections.
- User-friendly interface.
- Clean and simple layout.

## Technologies Used
- HTML5
- CSS3

## Project Structure
- HTML file – Contains the application form structure.
- CSS file – Handles styling and layout.

## How to Run
1. Clone the repository.
2. Open the `04-Job-Application` folder.
3. Locate the main HTML file.
4. Open it in your browser.
