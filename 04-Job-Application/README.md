# Job Application Form

## About
A web-based Job Application Form designed to collect applicant information through a simple and user-friendly interface.

## Features
- User-friendly application form.
- Collects applicant details.
- Organized form layout.
- Responsive web design.
- Simple and easy-to-use interface.

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Open the project folder.
2. Locate the index.html file.
3. Double-click index.html to open it in your browser.
4. Fill in the application form.

## Project Structure
- index.html - Main application page.
- CSS files - Styling and layout.
