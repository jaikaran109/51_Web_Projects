# Web Calculator

## Overview
Web Calculator is a browser-based application designed to perform mathematical calculations through an interactive calculator interface.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/15-Calculator

## Features
- Calculator interface.
- Number input controls.
- Arithmetic operations.
- Result display.
- Interactive buttons.
- Error handling where implemented.

## Supported Operations
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- HTML file – Calculator structure.
- CSS file – Calculator styling.
- JavaScript file – Calculation functionality.

## How to Run
1. Clone the repository.
2. Open the `15-Calculator` folder.
3. Locate `index.html`.
4. Open it in your browser.
5. Use the calculator controls to perform calculations.
