# Notes API with MongoDB

## Overview
Notes API is a backend web development project built using Node.js, Express.js, and MongoDB. It demonstrates how REST APIs can be developed to manage notes and interact with a database.

## How to Run

### Prerequisites
- Node.js
- npm
- MongoDB
- Postman (recommended for API testing)

### Installation

1. Clone the repository.

   `git clone https://github.com/jaikaran109/51_Web_Projects.git`

2. Navigate to the project directory.

   `cd 51_Web_Projects/21-Notes-Api_MongoDB`

3. Install dependencies.

   `npm install`

4. Configure the MongoDB connection using the environment variable names expected by the project.

5. Start MongoDB or configure your MongoDB Atlas connection.

6. Run the start command defined in `package.json`.

7. Test the API endpoints using Postman.
