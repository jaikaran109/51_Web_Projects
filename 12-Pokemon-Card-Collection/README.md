# Pokémon Card Collection

## Overview
Pokémon Card Collection is a frontend project designed to display Pokémon cards in an organized collection interface. It provides practice in presenting visual data through card-based layouts.

## Live Demo
Not currently published.

## Source Code
https://github.com/jaikaran109/51_Web_Projects/tree/main/12-Pokemon-Card-Collection

## Features
- Pokémon card collection interface.
- Card-based layout.
- Visual presentation of Pokémon.
- Organized collection display.
- JavaScript-based interactions where implemented.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- HTML file – Main application structure.
- CSS file – Card styling.
- JavaScript file – Application functionality.
- Assets – Images and other visual resources.

## How to Run
1. Clone the repository.
2. Open the `12-Pokemon-Card-Collection` folder.
3. Locate `index.html`.
4. Open it in your browser.

## Learning Outcomes
- Working with repeated UI elements.
- JavaScript DOM manipulation.
- CSS card layouts.
- Organizing visual content.
